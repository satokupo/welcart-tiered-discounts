# Welcart Tiered Discounts

このブランチ（dev）は、制限時間を超えてから調整を加えた参考版です。主たる提出対象は[mainブランチ](https://github.com/satokupo/welcart-tiered-discounts/tree/main)です。

Welcartに、商品代金に応じた自動のステップ割引を追加する独立したWordPressプラグインです。管理画面で複数のしきい値を設定し、カート・購入確認画面・確定後の受注データへ同じ割引結果を反映します。Welcart本体とテーマは変更しません。

## 導入

1. WordPressとWelcartを用意し、Welcartを有効にします。検証したバージョンは下の「検証環境」を参照してください。
2. このリポジトリの`plugin/`の中身を、`wp-content/plugins/welcart-tiered-discounts/`に配置します。
3. WordPressのプラグイン一覧から「Welcart Tiered Discounts」を有効にします。

## 割引設定

WordPressの「設定」→「ステップ割引」を開き、次の2段を登録して保存します。初期状態は割引なしです。

| しきい値金額 | 方式 | 割引値 | 状態 |
|---|---|---|---|
| 10,000円 | 固定額 | 500円 | 有効 |
| 30,000円 | 固定額 | 2,000円 | 有効 |

判定の基準は、全商品の登録販売価格×数量の合計です。定価・参考価格、送料、手数料、税抜運用で別途加算する消費税、利用ポイントは含めません。条件を満たす有効な段のうち、しきい値が最も高い1段だけを適用し、複数段の割引は合算しません。

固定額のほか、割合（小数第2位まで）も設定できます。割合の割引額は円未満を切り捨て、いずれの方式でも割引額は商品代金を上限にします。

## 動作確認手順

以下は、上記の2段を保存し、税込登録・税率10%、送料・手数料・利用ポイントが0、他の割引や標準キャンペーンを使わない条件で確認します。テスト用の商品・購入者情報を使い、実取引を伴わない振込方式などで注文してください。

1. **カートで割引を確認**: 登録販売価格が税込10,000円の商品を1個入れます。商品小計10,000円、ステップ割引500円、請求額9,500円になることを確認します。
2. **上位の段への切替を確認**: 同じ商品の数量を3個に変更します。商品小計30,000円、割引2,000円、請求額28,000円になることを確認します。割引は2,500円にはなりません。
3. **購入確認画面と保存結果を照合**: そのカートから購入手続きを進め、購入確認画面でも商品小計30,000円、割引2,000円、請求額28,000円であることを確認して注文を確定します。Welcartの受注一覧からその注文を開き、保存された3つの金額が一致することを確認します。
4. **受注編集を確認**: その注文の数量を1個に変更し、「ステップ割引を再計算」を押します。商品小計10,000円、割引500円、請求額9,500円の表示を確認して保存し、受注を開き直して金額と保存済み変更履歴を確認します。

受注編集では、注文時点の全割引設定で計算します。注文後に店舗の設定を変えても、過去の受注へ自動適用しません。購入確認後に適用条件が変わった場合は、更新された内容を再確認してから確定します。

## 制約・未対応

- 他の割引プラグイン・Welcart標準キャンペーンとの併用は保証対象外です。
- 外部決済の実取引とメールの実配送は未検証です。検証環境ではローカル振込方式とメール送信抑止を使用しています。
- カテゴリ・会員ランクによる除外、日本語・英語の翻訳提供は後続対象です。追加文言は翻訳関数を使用しています。
- 保存済み割引設定が破損している場合は、注文確定を停止します。管理者が設定とWordPress/PHPのエラーログを確認してください。プラグインを無効化しても、既存受注と注文時の記録は削除しません。
