# Welcart Tiered Discounts

Welcart 向けの独立 WordPress プラグインを開発するリポジトリです。開発対象のソースは `plugin/` に置き、WordPress 本体、Welcart 本体、テーマ、データベースは Docker のランタイム側で管理します。
