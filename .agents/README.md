# `.agents/` の役割

このディレクトリは条件付きRule（`conditional-rules/`）の置き場所。

## 判断軸

- **読むとAIの次の行動が変わるもの** → `conditional-rules/`
- **参照される資料（背景・仕様・記録）** → `docs/`

迷ったら「これを読まなければ何も変わらないか」で判定する。変わらないなら `docs/`。

## ルール

- routerテーブルはここではなくルート `AGENTS.md` の「条件付きRule router」に置く
- 各ファイルは1つの発火条件に絞る（複数条件を1ファイルに詰め込まない）
- ファイルを追加したら `AGENTS.md` のrouterへ1行追加する
