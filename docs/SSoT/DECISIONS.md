# DECISIONS — 判断ログ（索引）

> **見出しだけを持つ索引**。決定の中身は `decisions/` 配下の個別ファイルにある。
> ここを読めば「どんな決定があるか」が分かり、必要なものだけ開けばよい状態を保つ。

## 構成

- 1決定＝ `decisions/YYYY/MM/YYYY-MM-DD_タイトル.md` の**個別ファイル1枚**
- `decisions/` は最初の決定を記録する時点で作る（空の状態では存在しない）
- 本書は索引。決定の本文（決定・理由）も、決定を横断した要約・テーマ別のまとめも本書に書かない（まとめは仕様文書の側が持つ。`README.md` の役割分担を参照）

## 書式ルール

### 個別ファイル

- ファイル名は `YYYY-MM-DD_タイトル.md`（日付は決定した日、タイトルは内容を表す短い意味名）
- 中身は `# YYYY-MM-DD: タイトル` 見出し＋ **決定**・**理由** の2項目
- **作成後の書き換え禁止**。決定を変えるときは新しい個別ファイルを作り、本文に「`YYYY-MM-DD_◯◯` を上書きする」と宣言する（旧ファイルは消さず残す）
- 記録対象は「後から理由を問われる非自明な判断」のみ（誤字修正・整形は対象外）
- **秘密値・個人情報・非公開原文を書かない**（git 履歴に恒久に残るため。必要なら安全な識別子で参照する）

### 索引（本書）

- 個別ファイルを作ったら、**同じ作業内で**下の一覧へ1行追記する（古い順・末尾追記）
- 上書きが起きたときは、上書きされた側の行末へ `→ YYYY-MM-DD_◯◯.md で上書き` を**必ず追記する**（**索引で許される唯一の既存行の編集**。これが無いと、個別ファイルだけを開いた読み手が失効に気づけない）
