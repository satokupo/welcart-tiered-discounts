# MVP 定義

## MVP に含めるもの

| 項目 | 範囲・仕様の正本 |
|---|---|
| 独立プラグイン | [課題条件](ASSIGNMENT_REQUIREMENTS.md) の既存フック・フィルタによる連携、本体・テーマ非改変を満たす。 |
| 店舗共通の割引設定 | 複数のティアをまとめた一覧を 1 組管理する。各ティアで固定額・割合を選択できる。 |
| 自動判定・割引計算 | [機能仕様](FUNCTIONAL_SPEC.md) の判定・計算・端数処理に従う。 |
| 管理画面 | ティアの設定と保存、課題指定の保存時保護を含める。 |
| 標準ポイントとの併用 | Welcart 標準ポイント利用時の金額整合を含める。 |
| 表示と受注の整合 | カート、購入確認、確定後の受注データを必須対象とし、関連経路への影響も確認する。 |
| 翻訳の準備 | 管理画面とフロントへ追加する文言を翻訳可能に書く。 |
| テストコード | TDD に伴う成果物として、計算・保存保護・連携結果を確認できるテストをリポジトリ内へ含める。 |

固定額割引と割合割引は、段階式割引の各ティアで選ぶ方式である。3 つの独立機能として扱わない。

日本語・英語の翻訳提供と切替確認は MVP 完成後に行う。翻訳の準備と日英対応の完成を区別する。

## MVP に含めないもの

- Welcart 標準キャンペーンおよび他の割引プラグインとの併用
- 商品カテゴリによる適用対象の選択・除外
- 会員ランクによる適用対象の選択・除外
- 導入ウィザード／オンボーディング画面
- 複数の独立したキャンペーンの管理
- 将来機能のための汎用ルールエンジン

これらは MVP の対象外であり、恒久的な禁止ではない。後続候補・優先順は [マイルストーン](../work/MILESTONES.md) と [後続機能](../work/todo/POST_MVP.md) を参照する。恒久的に作らないと合意した製品機能は、現時点ではない。

## 完了条件

1. 上記の MVP 機能が [機能仕様](FUNCTIONAL_SPEC.md) の受入例・例外条件を満たす。
2. [確認事項](OPEN_QUESTIONS.md) のうち MVP の計算・保存・受注結果を左右する項目が解消され、対象バージョンで連携を確認できる。
3. [技術構成と運用](TECH_STACK_AND_OPERATIONS.md) の主受入れ環境で必須検証と品質検査を通し、補助環境の試行結果を記録する。
4. [課題条件の提出物](ASSIGNMENT_REQUIREMENTS.md#提出物) が揃い、評価者が再現できる。

環境準備の PASS は割引機能の PASS を意味しない。期限内に未完成部分がある場合の扱いは課題条件に従い、MVP 完成とは区別する。
