# 2026-08-28: 品質ツールを専用 PHP コンテナへ固定する

- **決定**: PHP 8.3.33 の専用品質ツールコンテナに Composer 2.10.2 を固定し、WPCS 3.4 系列、PHP_CodeSniffer 3.13 系列、PHPUnit 9.6 系列を `composer.lock` から project-local に導入する。`dealerdirect/phpcodesniffer-composer-installer` だけを Composer plugin として明示許可し、PHP lint、WPCS、PHPUnit runner、Plugin Check の標準入口を同じコンテナから提供する。
- **理由**: ホストの PHP や Composer の版・拡張へ依存せず、プラグインソースを同じ toolchain で検査できるようにするため。環境準備では機能テストや割引処理を追加せず、runner の設定読込みと起動可能性を確認する境界を保つため。
