# 2026-08-28: 検証環境の版と保証境界を固定する

- **決定**: 主開発・主受入れの `recommended` を WordPress 7.0.4 / PHP 8.3 / MySQL 8.4.11 / Welcart 2.12.1 / WordPress 同梱テーマに固定する。前方互換性の観測用 `latest` は WordPress 7.1 / PHP 8.5 / MySQL 26.7.0 Innovation / Welcart 2.12.1 / WordPress 同梱テーマ、公称下限の観測用 `minimum` は WordPress 5.6.19 / PHP 7.4 / MySQL 5.5.62 / Welcart 2.12.1 / WordPress 同梱テーマに固定する。`minimum` の MySQL だけは `linux/amd64` とし、`latest` と `minimum` は実行・記録を必須、成功を必須としない。
- **理由**: WordPress と Welcart の主な検証対象を推奨環境へ揃えながら、最新環境と公称下限の境界を別証拠として残すため。PHP 8.2、Welcart Basic、浮動する DB 版を主環境や保証範囲へ持ち込まず、認証付き配布物や Apple Silicon 非対応の MySQL 5.5 系を、固定した境界として明示的に扱うため。
