# 2026-09-07: 連携資料と確認事項を分離する

## 決定

`INTEGRATIONS.md` を、既存関数・フック・フィルタの公式参照先、候補と採用理由を管理する正本として追加する。`OPEN_QUESTIONS.md` を、ユーザー確認結果と実装前の実測事項を追跡する一覧として追加する。

TDD・対象コードと UI の確認・検証記録に関するプロジェクト固有の行動ルールは `.agents/conditional-rules/plugin-development.md` に置き、root `AGENTS.md` から到達できるようにする。

## 理由

課題が求める選定理由と、ユーザーが求める参照しやすい API 一覧を同じ場所へまとめるため。公開資料の存在と実際の採用・動作確認を混同せず、未確認の技術的詳細を確定仕様へ書き込まないため。仕様と AI 向け手順の配置は既存の正本境界に合わせる。
