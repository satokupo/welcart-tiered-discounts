# 2026-09-07: 割引設定を Options API へ保存する

## 決定

ユーザー回答により、割引設定は WordPress の通常設定として Options API に保存する。MVP は店舗共通の 1 組・全商品対象とし、具体的な構造を `DATA_MODEL.md` に置く。カテゴリ選択のための新しいカスタムタクソノミーは今回採用しない。

## 理由

現在必要なのは小さな設定一覧であり、商品と新しい分類を紐づける管理は必要ない。通常設定を採っても、将来、既存の商品カテゴリで対象を選ぶ機能は追加できる。割合の小数第 2 位を正確に保存するため、内部値はパーセントの 100 倍の整数とする。
