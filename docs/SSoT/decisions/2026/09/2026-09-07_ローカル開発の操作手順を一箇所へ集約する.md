# 2026-09-07: ローカル開発の操作手順を一箇所へ集約する

## 決定

ユーザー指示により、ローカル開発の初回設定・起動・停止・接続確認を含む操作手順を `LOCAL_DEVELOPMENT.md` へ集約する。root README に起動コマンドを置く配置を変更し、README は同文書への案内だけを持つ。ローカル開発に限り、SSoT 内で運用方針と再利用する操作手順を一緒に管理する。個々の実行結果・稼働状態は引き続き実測記録・作業記録で扱う。

## 理由

ローカル開発だけに使用する情報を、環境の説明から離れた README と二重管理せず、利用時に一つの文書から起動・確認まで辿れるようにするため。
