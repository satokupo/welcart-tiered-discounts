# 2026-09-07: 開発環境を再利用しDB更新をコードで統合する

## 決定

ユーザーとの合意に基づき、ローカル開発・worktree・DB 更新の方針を `LOCAL_DEVELOPMENT.md` に集約する。推奨版の A〜E を独立した永続環境として使い回し、作業ブランチの DB 更新処理をコードと共に main へ統合した後、各環境が対応コードを取り込んだ時に適用する。開発 DB の実体はマージしない。

## 理由

共有 DB では未採用の構造変更や設定変更が main・他の作業を壊す一方、毎回の新規インストールは短い worktree 作業の負担になる。環境の分離と再利用を両立させ、採用済みの変更だけをコードと DB の整合を保って展開するため。バージョン構成とは異なる運用上の関係を 1 枚で参照できるよう、専用 SSoT を新設した。
