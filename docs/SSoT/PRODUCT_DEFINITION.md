# プロダクト定義

## 作るもの

Welcart に、商品の購入金額に応じた段階式の自動割引を追加する独立した WordPress プラグイン。店舗の管理画面で複数段の割引条件を設定し、購入時には該当する割引を自動で反映する。

採用課題として、動作に加え、拡張経路の選定、検証、AI 出力の判断・修正の根拠を評価者が確認できる成果物を作る。課題提供者の条件は [課題条件](ASSIGNMENT_REQUIREMENTS.md) を正本とする。

## 利用者と利用場面

| 利用者 | 利用場面・得られること |
|---|---|
| 店舗管理者 | 管理画面で購入金額ごとの割引条件を管理する。Welcart 本体やテーマのファイルを書き換えずに導入する。 |
| ショップの購入者 | 通常のカート・購入手続きを進めながら、自動適用された割引と支払金額を確認する。 |
| 課題の評価者 | README から動作を再現し、画面・受注データの整合、設計理由、テスト、AI 活用の過程を確認する。 |

解消する課題は、店舗が設定した段階式割引を購入手続きと受注結果へ一貫して反映できるようにすること。売上向上率などの数値目標は定めていない。

## 将来の方向

将来の商品カテゴリによる対象選択を追加できる構造を保つ。現在の範囲は [MVP 定義](MVP_SCOPE.md)、構造上の境界は [データモデル](DATA_MODEL.md)、後続候補と順序は [マイルストーン](../work/MILESTONES.md) を参照する。

商用配布、課金、一般公開後の継続保守の方針は未決。採用課題の提出を、これらの実施決定とは扱わない。
