## 課題

Welcart に「カート合計金額に応じた自動割引機能」を、独立した WordPress プラグインとして追加する。

## 必須要件

- 独立したプラグインとして実装し、Welcart 本体およびテーマのファイルを改変しない
- 管理画面から、しきい値金額と割引額を複数段設定できる
  - 指定例: 10,000 円以上で 500 円引き
  - 指定例: 30,000 円以上で 2,000 円引き
- 割引結果を次の 3 箇所で整合させる
  - カート画面
  - 購入確認画面
  - 確定後の受注データ
- Welcart の既存フックおよびフィルタのみで実現する
- 設定保存時に次の保護を実装する
  - nonce 検証
  - 入力サニタイズ
  - 権限チェック
- WordPress コーディングスタンダード（WPCS）に準拠する

## 加点要件

次の項目は任意であり、必須要件へ読み替えない。

- 特定の会員ランクや商品カテゴリを除外する条件設定
- i18n 対応
- テストコード

- WordPress および Welcart は wordpress.org から無償で取得できる
