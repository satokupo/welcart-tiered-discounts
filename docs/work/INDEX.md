# 作業インデックス

> **見出しだけを持つ索引**。詳細は各ファイルにある。ここを読めば何があるか分かる状態を保つ。
> 更新は `work-record` スキルが行う（`save-chatlog` から自動で呼ばれる）。

## 構成

| 場所 | 何が入るか |
|---|---|
| `MILESTONES.md` | 開発の大枠（引き出し）。どの順番で進めるか |
| `todo/` | これからやること |
| `pending/` | 一旦保留（**再開の条件**を書く） |
| `done/` | 着手して完了 |
| `archive/` | **やらないと決めた**もの（判断理由を書く） |
| `log/YYYY/MM.md` | 作業と、そのとき下した判断（**月ごとに1ファイル**）。`todo/` に紐づかない作業も入る |

フォルダは必要になった時点で作る（空の状態では存在しない）。記録の5分類は `~/dotfiles/agents/conditional-rules/record-routing.md` が正本。
