## 商品カテゴリによる対象選択

店舗の税区分に従った、対象商品の減額前の登録販売価格の小計だけでティアを判定し、その対象商品代金に割引を適用する。対象外商品をしきい値の達成にも割引対象にも含めない。

例: 食品 3,000 円以上で 500 円引きの場合、食品 2,000 円＋雑貨 1,000 円では適用しない。食品 3,000 円＋雑貨 1,000 円なら、食品の商品代金全体から合計 500 円を 1 回引く。

対象カテゴリの限定と除外は「対象商品の選択」として検討する。両方の指定を提供するか、対象指定をティア一覧共通にするかティアごとにするか、複数カテゴリ所属・親子カテゴリの扱いは着手時に決める。対象外商品への割引配分と税の整合も確認する。

MVP の保存構造の正本は [データモデル](../../SSoT/DATA_MODEL.md)。上記の将来像を理由にカテゴリ UI や汎用ルールエンジンを先行実装しない。

## 標準ポイント適用後の金額による判定

標準ポイントで減額した後の金額を、しきい値判定と割引計算の基準にする方式を追加候補とする。MVP の減額前価格による方式とは区別する。優先順位は未決で、既存の日英・カテゴリ・ウィザードの順序へ自動挿入しない。

MVP では対象小計を組み立てる処理とティア選択・計算処理を分け、後続で入力金額の作り方を変更できる責務境界だけを保つ。未使用のモード設定・ポイント配分・汎用条件エンジンは先行実装しない。
