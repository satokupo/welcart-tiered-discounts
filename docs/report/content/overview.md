# 提出物について

プラグインは、次の2つのバージョンを用意しています。

- **提出版（main）**：想定作業時間を区切りとして、その時点で実行中だったAIの一括処理が終わるまで待ち、簡易的なレビューとそれに必要な修正を行って終了した版です。
- **翌日の追加調整版（dev）**：提出版で検証が不足していた箇所について追加検証を行い、調整を加えた版です。

提出版は、以下の時間配分で作成しました。
**AIの処理待ちを含めて約8時間となり、想定の5〜7時間を超過しています。**
休憩、環境準備、提出資料の作成、翌日の追加作業は、この内訳には含めていません。

| 工程 | 内容 | 所要時間 |
|---|---|---|
| 詳細計画まで | 要件整理、UIサンプル作成、設計・詳細計画、レビュー | 約5時間 |
| AIによる実装（一括実行） | TDDによる実装・検証・自己チェック | 約2時間30分 |
| 実装後の簡易全体レビュー | 別モデルによるレビュー、指摘の修正と回帰テスト | 約30分 |

普段の個人開発では、AIの処理待ちに別タスクの計画や小規模な修正を進めています。
また、実装に長時間かかる場合は、詳細計画を固めて業務終了時に実行し、翌日に結果を確認する進め方も取っています。
今回はその待ち時間も含めて、約8時間として計上しました。
